# Exploratory Data Analysis (EDA) on Books Dataset - CodeAlpha Task 2

This repository contains the solution for Task 2 of the CodeAlpha Internship. The project focuses on performing Exploratory Data Analysis (EDA) on a books dataset to uncover patterns, trends, and key insights using Python's data science stack.

## Key Features

- **Data Cleaning & Preprocessing:** Handling missing values, formatting data types, and restructuring raw data.
- **Statistical Analysis:** Computing summary statistics to understand data distribution and feature relationships.
- **Data Visualization:** Creating graphical representations (e.g., histograms, scatter plots, bar charts) to highlight trends across book ratings, authors, and genres.
